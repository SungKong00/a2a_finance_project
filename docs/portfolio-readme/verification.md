# 시연과 A2A 통신 검증

README 영상은 구현 브랜치에 포함된 [AVGO 저장 응답](https://github.com/SungKong00/a2a_finance_project/blob/f2d3fffd1211459df9191cfff2e3f5de7a4d8ae2/demo/ui/mock_data/AVGO_FULL_ANALYSIS.json)을 브라우저에서 재생해, 요약과 네 종류의 분석 카드가 표시되는 과정을 담았습니다.

별도 로컬 통신 확인은 A2A SDK와 에코 서버로 실행했습니다. AgentCard 조회와 메시지 요청이 성공했고, 완료된 Task와 메시지를 담은 Artifact가 반환됐습니다. Gemini 호출이나 시장 데이터 제공자의 응답을 확인하는 테스트와는 별개입니다.
